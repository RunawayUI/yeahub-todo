# Цель задания:

Научиться создавать элементы DOM через JavaScript, стилизовать их, а также управлять их состоянием и событиями.

## Задача:

Создать страницу To-Do List с функциональностью:

Добавление новых задач через форму с полями:

* **Название задачи**.
* **Дедлайн**.
* **Ответственный**.
* **Кнопка Submit**.

Отображение списка задач.

Возможность отметить задачу как выполненную:

* Если задача выполнена, её фон становится светло-зелёным.
* Невыполненные задачи имеют нейтральный фон.

Данные о задачах (тайтл, дедлайн, ответственный) должны быть видны в списке.

## Пошаговое задание:

### Создайте структуру страницы:

* Используя JavaScript, добавьте заголовок и форму для добавления новых задач (с полями: название задачи, дедлайн, ответственный, кнопка Submit).

### Добавьте функционал для формы:

* Сделайте так, чтобы при нажатии кнопки Submit данные из формы добавлялись в список задач.
* Если одно из полей формы пустое, отображайте сообщение об ошибке.

### Отображение списка задач:

* Каждая задача должна отображаться в виде:

  * Названия задачи.
  * Дедлайна.
  * Имени ответственного.
  * Чекбокса "Выполнено".

### Добавьте функциональность для отметки задачи как выполненной:

* Если задача выполнена, измените фон задачи на светло-зелёный.
* Если задача снова отмечена как невыполненная, верните исходный фон.

### Добавьте стилизацию:

* Примените базовые стили для заголовка, формы, списка задач и кнопки.
